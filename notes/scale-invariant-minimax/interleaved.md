# 长短交错的重置周期：上界与两类排除结果

模型、\(a(u)\)、\(s(u)\) 和随机对数相位沿用[尺度极限证明](README.md)。时间单位是 \(x_0^2\)，风险为 \(\sup_{x\ge x_0}\mathbb E T_x/x^2\)。以下数值的最终比较均为有理数比较。

| 六轮非等比块，参数见下 | 3.577833426 |
| 每一个长轮次之后插入长度为其千万分之一的短轮次 | 3.577825256 |
| 每 4096 轮交换一对相邻的普通时限 | 3.577863477 |
| 每 \(2^{25}\) 轮交换一对 | 3.577824971 |

六轮策略已严格低于原上界 3.57787。更精细的比较显示，原倍率 \(193/120\) 的**理想周期平均**在 \((3.5778249744078,3.5778249744081)\) 内。将单轮对数增量调为 \(h=0.47525052\)，理想均值降至 \((3.5778249658326,3.5778249658330)\)。任意固定的有限起点，在 \(x\to\infty\) 时，删去前缀的归一化时长一致趋于零，因而半轴上的上确界至少为理想均值。故稀疏交换策略的上界可严格小于旧倍率实际策略的最坏值。固定新倍率时，交换本身会增加代价，见第 2 节。没有证据表明交错优于重新调参的等比表。

五点下界仍是 \(15756304/4621875\)。现在缺口为 \(3.577824966-15756304/4621875\approx0.16875310664\)。下文还证明，两轮周期块的整个连续参数族都有严格下界 3.54；其计算不使用这条五点下界。

## 1. 可实现的表与相位积分证书

对块乘数 \(B=e^L\)、对数时限 \(v_i\)，取 \(U\sim{\rm Unif}[0,1)\)，第 \(j\) 块的时限为 \(x_0^2\exp((j+U)L+v_i)\)，依次执行。六轮表使用以下**精确十进制数**：
\[
L=1.42575,\qquad (v_i)=(0,-2.079442,-10.165846,12.237651,12.712905,13.188126).
\]
其第二轮约为第一轮的八分之一，第三轮又明显缩短。第一块索引取 \(-44\)。千万分之一短探针表使用 \(L=h,(v_i)=(0,-\log 10^7)\)，第一块取 \(-104\)。这些表都有首轮且有限时间内只有有限次重置。

对数相位 \(p\in[0,L]\) 下，将保留计算的各轮 \(u=\exp(jL+v_i+p)\) 由后到前递推 \(V=a(u)+s(u)V_{\rm next}\)，终值为零。若计算的块索引为 \(l,\ldots,H\)，\(D=\sum_i e^{v_i}\)，则过去所有时限之和一致不超过 \(\eta=B^{l+1}D/(B-1)\)。由 \(1-s(u)\le u\)，过去的存活概率至少为 \(1-\eta\)。向未来，在零相位从第 0 块至第 \(H\) 块各存活率的乘积 \(P\) 是到达余项的统一上界。令 \(c=\max_i e^{v_i}\)，若 \(q=B s(c B^{H+1})<1\)，余项至多为 \(P B^{H+2}D/(1-q)\)。程序分别检验 \(\eta<2\cdot10^{-21}\) 和余项小于 \(10^{-21}\)。记有限递推的相位平均为 \(I\)，则理想平均夹在 \((1-\eta)I\) 与 \(\eta+I+\text{余项}\) 之间；实际截断表的半轴上界是在后者基础上再除以 \(1-\eta\)。

相位积分用 160 位 Arb 实球及 Taylor 系数验证。每格中心为 \(p\)，半宽为 \(d\)。设 \(c_k=V^{(k)}(p)/k!\)，用整格作为中心参数再算一次，得到包住所有 \(V^{(8)}(\xi)/8!\) 的区间 \(E_8\)。格平均满足
\[
\left|\,I_{\rm cell}-\sum_{k=0,2,4,6}c_k\frac{d^k}{k+1}\,\right|
\le \sup|E_8|\frac{d^8}{9}.
\]
核的 Taylor 系数由 \(d a/dp=u s\)、\(d s/dp=-z e^{-z^2}/\sqrt\pi\)、\(z=1/\sqrt{2u}\) 生成，后向递推同样使用区间幂级数。最终将上下端分别向外舍入为分母 \(10^{14}\) 的有理数。

## 2. 相邻交换的精确代价

以 \(r=e^h\) 的表为基准。把相邻的 \(u,v\) 对调，在固定距离下，归一化总成本的变化恰为
\[
P_{\rm before}\,[\,a(v)(1-s(u))-a(u)(1-s(v))\,].
\]
因为这两轮都失败的概率仍为 \(s(u)s(v)\)，此前所有**互不重叠**的交换也不会改变到达下一对的概率。因此多个不重叠交换的改变量相加。令 \(G_0\) 为等比表的理想均值，\(G_2\) 为每对都交换的理想均值，程序验证 \(3.6566951045184<G_2<3.6566951045187\)。

每 \(M\ge2\) 轮只交换一对时，在一个基本倍率的均匀相位之外，再在 \(0,\ldots,M-1\) 中均匀选交换的起始余数。这等价于在整个超级周期均匀随机相位。每个潜在的交换位置被选中的概率是 \(1/M\)；每对都交换的随机相位表对应概率 \(1/2\)。由线性性，
\[
G_M=(1-2/M)G_0+(2/M)G_2.
\]
交换差的绝对和可由各对交换前后非负成本和控制：把所有可能的起点分成奇偶两组，每组是不相交交换，两张表的相位平均均有限。这允许交换求和与相位积分。因 \(G_2>G_0\)，孤立交换的损失符号已严格确定。

合法实现选择一个基本相位和一个随机余数，只执行原索引 \(n\ge-110\) 的轮次（先按余数确定交换后的时限）。每轮变动至多一个倍率，删去时限之和一致不超过 \(r^{-108}/(r-1)\)。程序据此验证表中的三个上界。即使超级周期很长，运行时也只需一个模 \(M\) 计数器。

## 3. 两轮周期的连续参数排除

令时限表为 \((1,q)B^j\)，\(g=\log B>0,\ d=-\log q\)。任一两轮正时限块都可通过整体缩放写成这种形式。循环移动起点并重新定标把 \(q\) 变成 \(B/q\)，同一理想相位平均可取 \(q\le\sqrt B\)，即 \(d\ge-g/2\)。相位积分展开所有块，令 \(v\) 为当前块首轮的对数归一化时限。由 Tonelli 有
\[
G(g,d)=\frac1g\int_{\mathbb R}
H_g(v)H_g(v-d)
[\,a(e^v)+s(e^v)a(e^{v-d})\,]\,dv,\qquad
H_g(v)=\prod_{j\ge1}s(e^{v-jg}).
\]

**小倍率。** \(h_1(u)=1-s(u)\le3u^2\)，因为单位距离首达时间的倒数与标准正态平方同分布。在任意相位上，取最后一个不超过 \(A=\sqrt{(1-B^{-2})/[6(1+B)]}\) 的首轮时限。由并集界，直到该块结束时的累计成功概率至多 \(3(1+q^2)A^2/(1-B^{-2})\le1/2\)。在都失败的事件上，至少付出了此前全部首轮时限的和。因此 \(G\ge A/[2(B-1)]=1/[2\sqrt6 B\sqrt{B-1}]\)。当 \(g\le1/512\) 时下界大于 3.54。

**大倍率。** 当 \(g\ge32\)，仅取 \(v\in[g/2-3,g/2-2]\)。先前失败概率至少为 \(1-(1+q)e^v/(B-1)\ge1-e^{-2}/(1-e^{-16})\)。对 \(u\ge1\)，有 \(a(u)\ge us(u)\ge\sqrt{2/\pi}e^{-1/2}\sqrt u\)。只计当前首轮，得到上述存活下界乘以 \(\sqrt{2/\pi}e^{-1/2} e^{g/4-3/2}/g\)，在 \(g\ge32\) 上递增，已足以超过 3.54。

**中间连续参数。** 在 \(1/512\le g\le32\) 上用有理端点矩形覆盖。\(H_g(v)\) 对 \(g\) 递增、对 \(v\) 递减。在参数格 \([g_l,g_r]\times[d_l,d_r]\) 以及积分格 \([v_l,v_r]\) 内，用 \(H_{g_l}(v_r)H_{g_l}(v_r-d_l)\)、左端的两个成本 \(a(e^{v_l}),a(e^{v_l-d_r})\)、右端的 \(s(e^{v_r})\)、以及 \(1/g_r\) 构造下界。对 \(d\ge16\) 的无界格，第二轮成本直接取零，存活因子仍有界。完全位于 \(d<-g/2\) 的矩形可以略过。积分只取 \([-24,18]\)，余下为非负项。

网格步长 \(1/512\)。核由 Arb 向下取整；为防累加溢出，成本下界还可截在 1000。生存无限乘积通过负对数的整数上界、按每个 \(g_l\) 的余数类依次累加、再查向下舍入的指数表求得。最左计算点为 \(-43\)，缺失的更早轮次总成功概率至多 \(\delta=e^{-43}/(1-e^{-1/512})\)，验证 \(2\delta<2^{-24}\)，故负对数留一个刻度即可。每个通过的参数格均直接以整数证明下界大于 3.54；阈值未通过则继续分裂。共通过 131,730 个矩形，其中最小的有理下界为 70800017/20000000。该结论覆盖连续的倍率和块内比例，也覆盖其截断策略的半轴最坏值，因为 \(x\to\infty\) 时有限起点的影响消失。

## 4. 十轮固定时限的全部重排

另取块倍率 \(r^{10}\)，固定时限集合 \(\{1,r,\ldots,r^9\}\)。允许每一周期重复同一任意排列。在对数归一化变量 \(v\) 上展开相位平均，分母为 \(10\log r\)。进入当前块之前的存活率是 \(\prod_{j<0}s(r^j e^v)\)，不依赖排列。在已用集合 \(S\) 后使用位置 \(k\) 的成本权为这个存活率乘 \(\prod_{j\in S}s(r^j e^v)a(r^k e^v)\) 的积分。故所有排列可用子集动态规划处理，增加一个布尔位记录是否已偏离递增顺序。

只积分 \(-48\log r\le v\le20\log r\)，用步长 \(\log r/256\)。成本取左端下界，存活取右端下界，乘积和积分全部向下取整。起点处尚未计入的成功概率用几何和控制。动态规划在所有 \(10!-1=3,628,799\) 个非恒等排列上求最小成本下界，得到
\[
1148157650125893/320000000000000>3.58799 .
\]
因此固定上述十个时限和倍率时，递增排列严格优于其余每种排列。该验证允许同一非恒等排列重复，不涵盖跨块改变排列或重新选择十个时限值。
