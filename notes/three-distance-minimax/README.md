# 未知距离的布朗搜索：三点最坏情况证书

考虑方差为 \(t\) 的一维布朗运动，瞬时重置到起点，重置后各轮运动独立。目标位置在整次搜索中固定。时限可依赖历次失败、自己选择过的时限以及独立随机数。搜索者仅观察是否已经命中。采用无有限时间内无限次重置的策略，未命中记作无穷搜索时间。归一化代价为 \(J_x=\mathbb E[T_x]/x^2\)。

## 定理

取 \(d=(1,63/20,143/16)x_0\)，初始权重 \(p=(125,279,256)/660\)。每个可容许策略 \(\pi\) 满足
\[
\sup_{x\ge x_0}J_x(\pi)\ \ge\ \max_k J_{d_k}(\pi)\ \ge\
\sum_{k=1}^3 p_kJ_{d_k}(\pi)\ \ge\ L=\frac{8410849}{2578125}.
\]
即使策略知道这三个候选位置及其权重，下界依然成立。相比先前的两点证书 \(50180079/16250000\)，提升约 0.1743850536。与新证明的全距离上界 3.57787 相距约 0.31548008。见[对数周期上界证书](../scale-invariant-minimax/README.md)。另有显式策略满足 \(\max_k J_{d_k}<3.262947\)，因此这组固定距离的最优最坏系数在宽度小于 0.000558 的区间内。

## 距离与权重的选择

以布朗缩放取 \(x_0=1\)，轮时限的单位为 \(x_0^2\)。初筛取中距离为 2.3、2.7、3.1、3.5、4，远与中距离比为 2.4、2.9、3.4；随后在中距离 3 至 3.375、远距离 8.5 至 9.625 一带选点加密。在每组三点上，用失败后的两个赔率为状态，离散化 Bellman 递推，并搜索使加权代价最大的初始赔率。选中中距离 3.15、远距离 8.9375。最终在固定三点的 \(1/256\) 赔率网格上，取已验证下界最大的节点；概率权重依次约为 18.94%、42.27%、38.79%。距离的搜索属于数值选点，尚未证明这组距离在所有三点配置中最优。

## 下界证明

以 \(x_0=1\)。设 \(u=t/d^2\)，单轮失败概率和归一化平均耗时为
\[
s(u)=\operatorname{erf}(1/\sqrt{2u}),\qquad
a(u)=\int_0^u s(v)\,dv
=u s(u)+\sqrt{2u/\pi}\,e^{-1/(2u)}-\operatorname{erfc}(1/\sqrt{2u}).
\]
记 \(a_k(t)=a(t/d_k^2),\,s_k(t)=s(t/d_k^2)\)。未归一化权重 \(w=(w_1,w_2,w_3)\) 下，本轮耗时为 \(w\cdot a(t)\)，失败后的权重为 \(D_t w=(s_1w_1,s_2w_2,s_3w_3)\)。

在 \(N=256\) 的网格上取 \(b_{ij}=(i/N,j/N,1)\)，\(0\le i\le140,\ 0\le j\le296\)。令 \(v_{ij}\) 为附录整数数组除以 \(10^6\)。定义
\[
F(w)=\max_{\lambda\ge0}\left\{\sum_{ij}\lambda_{ij}v_{ij}\;:\;
                 \sum_{ij}\lambda_{ij}b_{ij}\le w\right\},
\]
向量不等式逐坐标理解。零解可行，且 \(\sum\lambda_{ij}\le w_3\)，故最大值存在。\(F\) 逐坐标单调、正齐次且超可加，满足 \(v_{ij}\le F(b_{ij})\)、\(0\le F(w)\le 10w_3\)。这个定义无需假设数值节点的插值曲面整体凹。

验证器对每个节点、每个时限证明
\[
v_{ij}\le b_{ij}\cdot a(t)+F(D_t b_{ij}).
\]
把这些不等式乘以达到 \(F(w)\) 的系数并相加，利用代价、转移的线性，以及 \(F\) 的超可加性和单调性，得到 \(F(w)\le w\cdot a(t)+F(D_tw)\)。沿失败分支迭代。若三个平均时间均有限，远目标在第 \(n\) 轮后仍未命中的概率趋零，因而末项 \(F(w^{(n)})\le 10w_3^{(n)}\) 趋零。任一平均时间无穷时正权加权代价已无穷。对随机策略先固定全部独立随机数再积分。初始节点为 \(i=125,j=279\)，除以其三个坐标之和，得到 \(L\)。

## 连续时限与整数运算

- 当 \(0<t\le1/32\)，最近目标的成功概率 \(h_1(t)\) 满足 \(h_1(t)/t\le\sqrt{2/(\pi t)}e^{-1/(2t)}\)。右侧在该区间递增。验证器在右端验证 \(10h_1(t)\le t/(2d_3^2)\)。所有目标的存活概率至少为 \(1/2\)，故单是远目标的成本 \(a_3(t)\) 就足以抵消 \(F(b_{ij})\) 按最差存活率缩减的损失。
- 当 \(t\ge4096\)，验证 \(a_3(4096)>10\)，而全部节点值至多是 10。
- 中间时限用有理端点二分。在区间 \([l,h]\) 上，取左端耗时和右端失败概率的 Arb 下界，利用 \(a\) 递增、\(s\) 递减覆盖整个区间。三组失败概率向下舍入至分母 \(K=10^8\) 的数 \(s/K,v/K,S/K\)。求整数商余 \(is=kS+f,\ jv=mS+g\)。网格方格沿左下至右上对角线剖分。四个顶点的非负质量为 \(S-\max(f,g),(f-g)_+,(g-f)_+,\min(f,g)\)，再统一除以 \(K\)。这组系数精确合成向下舍入的三个存活权重，因此是 \(F\) 定义中的可行解。边界处数组填充零对应的质量为零。只细分尚未通过的节点；每次比较包括端点。
- 特殊函数用 144 位 Arb 球算术包围，最终节点比较使用带溢出界检查的整数运算。有 41,877 个节点。保存的整数数组是待验证的输入；验证不需要浮点优化正确，也不需要 scipy。

## 三个固定距离上的上界

脚本列出了三套确定性时限前缀和精确的随机混合概率。每个前缀结束后始终重复时限 73.25。固定距离的尾部成本为 \(a/(1-s)\)，依次向前代回 \(a+sJ_{\rm next}\) 并用区间算术加权。三个系数分别约为 3.262946081、3.262946553、3.262945620。这个上界只约束给定的三个目标；定理中的下界同时适用于允许全部距离的问题。
