# 四个候选距离下，逐轮布朗重置的最坏情况

一维标准布朗运动的方差为 \(t\)。目标位置在整个实验中固定，重置瞬时回到原点并开始独立的一轮。搜索者仅观察是否命中，允许根据此前的失败、自选时限及独立随机数选择以后各轮的时限。考虑不会在有限时间内累积无限次重置的策略；未命中记作无穷搜索时间。记 \(J_x(\pi)=\mathbb E_\pi T_x/x^2\)。所有距离除以 \(x_0>0\)，所有时限除以 \(x_0^2\)。

相对三点严格下界 \(8410849/2578125\) 提高约 0.092730978，与新证明的全距离上界 3.57787 相距约 0.22274911。此处更新了比较基准，原验证器输出的 gap 字段仍按历史参考值计算。见[对数周期上界证书](../scale-invariant-minimax/README.md)。只允许这四个距离时，显式随机策略给出上界 3.356404。该固定四点问题剩余宽度小于 0.001284。

## 选点与权重

缩放固定最短距离为 1，其余三个距离和三个自由权重均参与搜索。在两组相邻距离比的乘积网格上分别考察 27 个组合，然后在表现较好的区域进行两轮局部搜索（13 组和 6 组）。每个组合的评分同时在三维赔率网格上取最大值，完整候选列表与评分入口在 Python 脚本的 profile 函数中。前两轮最近两个目标的距离比覆盖 2.75 至 3.5，其余相邻比覆盖 2.5 至 3.25。末轮评分最高的组合为 \((1,3.25,9.25,25.25)\)。最终对该组合用更细的网格和向外取整重新求权重。以上过程给出可检验的选点，尚未证明其在所有四点组合中最优。

## 证书的数学依据

写 \(s(u)=\operatorname{erf}(1/\sqrt{2u})\)，
\[
a(u)=\int_0^u s(v)\,dv
=u s(u)+\sqrt{2u/\pi}\exp[-1/(2u)]-\operatorname{erfc}(1/\sqrt{2u}).
\]
这是单轮失败概率和单轮归一化平均耗时。写 \(a_m(t)=a(t/d_m^2)\)、\(s_m(t)=s(t/d_m^2)\)。对四目标的未归一化权重 \(w\)，本轮成本为 \(w\cdot a(t)\)，失败后的未归一化权重为 \(S_tw=(s_m(t)w_m)_m\)。

固定 \(D=120\)，用赔率节点 \(b=(i^2/D^2,j^2/D^2,k^2/D^2,1)\)；三个索引分别从零至 86、135、154。共 1,833,960 个节点。平方网格在低赔率区更密集。为节点赋有理数值 \(v_b\in[0,20]\)，定义
\[
F(w)=\max\{\sum_b\lambda_b v_b:\lambda_b\ge0,\ \sum_b\lambda_b b\le w\}.
\]
向量不等式逐坐标成立。系数之和至多 \(w_4\)，故最大值存在。\(F\) 单调、正齐次、超可加，并且 \(F(w)\le20w_4\)。若对每个节点、每个正时限有
\[
v_b\le b\cdot a(t)+F(S_tb),
\]
对达到 \(F(w)\) 的系数加权求和，就有 \(F(w)\le w\cdot a(t)+F(S_tw)\)。沿连续失败分支迭代，若所有四个均值有限，则远目标的剩余存活权重趋零，从而余项趋零；任一均值无穷时，正权加权下界自动成立。先固定随机种子再积分即覆盖随机策略。初始索引为 \((79,125,142)\)，以该节点权重之和归一化，得到定理。

## 全部正时限的验证

- 当 \(0<t\le1/64\)，最近目标的成功概率 \(h(t)\) 满足 \(h(t)/t\le\sqrt{2/(\pi t)}e^{-1/(2t)}\)，其右侧在该区间递增。用 Arb 在右端验证 \(20h(t)\le t/(2d_4^2)\)，且所有失败概率至少为一半。远目标的单轮成本已足以弥补把原节点值按最差失败率缩减的损失。
- 当 \(t\ge2^{19}\)，用 Arb 验证远目标的单轮成本大于 20，覆盖任一节点值。
- 中间 25 个二倍尺度区间各等分为 2048 份，共 51,200 个最细时间区间；可提前对整段证明。对任一区间取左端的成本下界、右端的失败概率下界。成本递增、失败概率递减，因而覆盖连续的整个区间。特殊函数用 144 位 Arb 球算术向外包围，各量再向下舍入成分母 \(K=3{,}000{,}000\) 的有理数。

节点不等式的见证由网格立方体的顶点给出。设四个失败概率的整数下界为 \(s_1,s_2,s_3,S\)（单位 \(1/K\)）。对索引 \(i\) 和相应 \(s\)，取最大的 \(h\) 使 \(h^2 S\le i^2s\)，并取余量 \(f=\lfloor(i^2 s-h^2 S)/(2h+1)\rfloor\)。于是 \(0\le f<S\)，\(h^2S+(2h+1)f\le i^2s\)。另两轴同理。对三个余量从大到小排序，将 \(S\) 减最大、相邻之差、最小余量依次分给一个四面体的四个顶点，各除以 \(K\)。所得非负系数精确合成了逐坐标不超过实际失败权重的向量，因此其续行代价是 \(F(S_tb)\) 的合法下界。

程序使用整数刻度 \(1/100000\) 按节点索引顺序构造 \(v_b\)。正质量顶点的索引逐轴不增，若出现当前节点，把对应系数移到左边；若全部质量等于原节点，正成本已使不等式成立。对实数上限向下取整并取候选区间下界的最小值。分支剪枝仅在整个区间的不等式已对当前候选值成立时使用；以后再降低候选值仍然有效。

## 复核与固定四点上界

区间表驱动两遍整数计算。第一遍按排序余量递推节点值。第二遍读取全部已经固定的值，直接验证节点不等式。它使用另一种顶点公式：对选择的升轴子集 \(A\)，顶点质量为 \((\min_{m\in A} f_m-\max_{m\notin A}f_m)_+/K\)，空集最小值取 \(S\)、空集最大值取零。必要时二分时间区间。两遍共享 Arb 端点表和逐轴商余，第二遍不再求解递推。整数运算在开始前用 128 位上界检查有符号 64 位中间量。整数平方根的浮点起始猜测由精确整数比较校正。

另外，Python 脚本给出四套确定性时限的有限前缀和开局混合概率。前缀后一直重复时限 584.645。尾段成本由几何级数 \(a/(1-s)\) 求得，前缀通过 \(a+sJ_{\rm next}\) 反向递推。四个距离的系数均经 Arb 验证小于 3.356404。此上界只用于衡量选定四点本身还能提供多少改进。
