# 未知目标距离下逐轮重置的严格代价

本地研究笔记。采用一维标准布朗运动（方差为 \(t\)），每次重置瞬时回到原点并独立开始下一轮。目标位置在整次搜索中保持固定。搜索者仅知道是否已命中，可以根据此前的失败、自己选择的时限和独立随机数决定下一轮时限。考虑无有限时间内无穷次重置的策略，未命中记作无穷搜索时间。通过布朗尺度变换，以最近目标距离为长度单位、其平方为时间单位。

## 定理

令 \(r=25/8\)，\(J_x(\pi)=\mathbb E_\pi[T_x]/x^2\)。定义
\(C_2=\inf_\pi\max(J_1(\pi),J_r(\pi))\)，允许策略事先知道这两个候选距离。令 \(c_*\) 为已知距离时同一策略类的最优归一化代价。则

\[
  2.671770\le c_*<2.671772,\qquad
  \frac{50180079}{16250000}\le C_2<3.088081 .
\]

因此连续距离 \(x\ge x_0>0\) 的最优最坏代价也至少是 \(3.088004861538\ldots\)。距离未知在最坏情况下至少多花 \(0.416232861538\ldots\) 个扩散时间单位，或者说至少增加 15.57%。与新证明的全距离上界 3.57787 相距约 0.48986514。见[对数周期上界证书](../scale-invariant-minimax/README.md)。两距离显式上界仅用于这两个候选目标。

## 单轮核与已知距离基准

设 \(u=t/x^2\)。由反射原理，一轮的成功概率、存活概率和归一化平均耗时分别为
\[
h(u)=\operatorname{erfc}(1/\sqrt{2u}),\quad s(u)=1-h(u),\quad
a(u)=\int_0^u s(v)\,dv
=u s(u)+\sqrt{2u/\pi}\,e^{-1/(2u)}-h(u).
\]
\(a,h\) 单调递增，\(s\) 单调递减。已知距离时 \(c_*=\inf_{u>0}a(u)/h(u)\)。任一轮有 \(a(u)\ge c_* h(u)\)。乘以到达该轮的概率再加总，对于有限均值策略，首次命中的总概率为 1，得到通用下界。反过来，反复使用同一时限的代价是 \(a(u)/h(u)\)，所以基准对任意逐轮与随机化策略均成立。验证器以 \(u=917/1000\) 见证上界，对所有 \(u>0\) 验证下界。重启首达时间的一般理论见 [Pal 与 Reuveni (2017)](https://doi.org/10.1103/PhysRevLett.118.030603)。

## 两个目标的下界

取近、远目标权重分别为 \(5/13,8/13\)，初始赔率 \(z_0=5/8\)。这组权重仅用于证明，因为任一策略的两个代价的最大值支配其加权平均。把远目标尚未命中的权重暂时归一化为 1，近目标的对应权重为 \(z\)。试一次时限 \(t\)，本轮的加权代价为 \(za(t)+a(t/r^2)\)。若没有命中，新的未归一化权重为 \(z s(t)\) 和 \(S=s(t/r^2)\)。新赔率 \(z'=zs(t)/S\le z\)，因为近目标更容易被命中。

构造连续分段线性凹函数 \(V\)，定义域是 \([0,5/8]\)。节点在 \(z_i=i/200\)，其中 \(0\le i\le125\)。随附脚本完整列出各节点值（整数除以 \(10^7\)）。所验证的不等式是
\[
 V(z)\le z a(t)+a(t/r^2)+ S V\!\left(zs(t)/S\right),\qquad t>0.
\]
固定 \(t\) 时右边关于 \(z\) 为凹函数，故只需验证全部节点。若将相邻节点间的线段延长，支撑直线可写为 \(m_jz+b_j\)，并有 \(V(z)=\min_j(m_jz+b_j)\)。验证器检查所有 \(m_j,b_j\) 均在 \([0,16]\)。因此齐次函数 \(F(v,w)=wV(v/w)=\min_j(m_jv+b_jw)\) 在两个坐标上均单调；其支撑线表示亦可用于比较向下取整的生存权重。

逐轮迭代不等式，累积预期代价加上存活分支上的末项 \(w_nV(z_n)\) 至少为初始势值。若两个距离的期望均有限，远目标的存活概率趋零，且 \(V\) 有界，因此末项消失；若任一个均值无穷，最坏情况下界自动成立。以独立随机数为条件，随机策略沿“至今全部失败”分支成为一个确定序列，此论证逐个适用并可取平均。由 \(V(5/8)=50180079/10^7\)，除以 \(1+5/8\) 即得定理的下界。该论证允许非单调时限和无限轮数。

## 连续参数的算术证书

- \(0<t\le1/16\)。高斯尾界给出 \(h(u)/u\le \sqrt{2/(\pi u)}\,e^{-1/(2u)}<1/32\)（右侧在该区间递增），故 \(a(u)\ge u s(u)\ge u/2\ge16h(u)\)。这对 \(u=t,t/r^2\) 都成立。对每条支撑线，本轮代价足以补回两个存活权重的损失，得到所需不等式。
- \(t\ge256\)。远目标的单轮耗时 \(a(256/r^2)>\max_i V(z_i)\)，已经足够。已知距离的基准同样由 \(a(256)>2.671770\) 控制。
- 中段用精确有理数二分。对每个闭区间 \([l,u]\)，耗时取左端点的下界，存活概率取右端点的下界。取已知距离基准时，成功概率取右端点的上界。特殊函数用 144 位 Arb 球算术向外包围，再舍入成分母 \(10^8\) 的有理数；全部比较用 Python 任意精度整数。根据节点凹性和两个权重上的单调性，这些比较覆盖整个区间。探索阶段的浮点优化只用于提出节点值，验证阶段无需信任优化或其网格。

## 检查这对距离本身的极限

验证器给出两套确定性时限序列。策略开局以 \(59221/100000\) 的概率选 A，否则选 B。两套序列的有限前缀之后均永远重复时限 8.955，所有时限单位是最近距离的平方。用单轮核逐项加总，重复尾段由几何级数精确求和。两个距离的归一化代价分别在 3.08808091734 和 3.08808093847 附近，均严格小于 3.088081。这把该距离对的最优值夹在宽度小于 0.000077 的区间内。挑选距离比的探索没有证明 \(25/8\) 是所有距离对中最强的一对。
